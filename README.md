A one-star review of Monday, written as though Monday were a restaurant — variant A, the service complaint: waited an hour to be seated, and the waiter turned out to be the alarm clock.

> Waited an hour to be seated. The waiter, my alarm clock, screamed at me, forgot my order, and served me Monday anyway. Would not return.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (and mirrors it to the repo-root `entry.txt` when writable). One line, 25 words, plain text.
